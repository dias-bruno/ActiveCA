# Selection of socioeconomic variables from the 1992 GSS Time Use Survey (Cycle 7).

This dataset contains some socioeconomic variables obtained from the
main file of the 1992 GSS Time Use Survey (Cycle 7). We labeled
variables according to the Public Use Micro Data File Documentation and
User's Guide (gss-12M0007-E-1992-c-7-m).

## Usage

``` r
data(gss_main_1992)
```

## Format

A data frame containing 9815 rows and 9 variables; each row represents a
unique respondent.

- SEQNUM:

  Record identification.

- FWGHT:

  Final Weight for Main File.

- SURMNTH:

  Survey Month of Questionnaire.

- FORMTYPE:

  Form Type - English or French.

- A4:

  How often do you feel rushed? Would you say it is.

- A5:

  Compared to 5 years ago, do you feel more rushed?.

- A6:

  How often do you feel you have time on your hands?.

- C2:

  Respondent has child(ren) \<15?.

- DVAGEGR:

  Age group of respondent.

- DVSEX:

  Sex of respondent.

- DVMS:

  Marital status of respondent.

- DVHHSCAP:

  Total number of persons living in the household.

- DVPROV:

  Province of residence of respondent.

- DVCMA:

  Derived Census metropolitan area.

- DVLVGRGR:

  Grouped living arrangement of the respondent.

- DVAGRYC:

  Age of respondents youngest single child.

- RESC0004:

  Number of respondents single children aged 0-4.

- RESC0512:

  Number of respondents single children aged 5-12.

- RESC1318:

  Number of respondents single children aged 13-18.

- RESC1924:

  Number of respondents single children aged 19-24.

- RESC2596:

  Number of respondents single children aged 25+.

- DVAGRSP:

  Age group of the respondents spouse.
